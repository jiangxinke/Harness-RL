Add `--native-phase-timing` to a native `dcc_model_evaluate.py` generation command or `dcc_collect_native_train.py generate` command to record phase timings. Evaluation requires `--native-thinking`. The flag is off by default; existing traces and configuration remain unchanged when it is omitted.

Each thought/JSON phase gains a `timing` object with local `time.monotonic()` seconds for dispatch, first/last observed response, validated phase completion or exception, abort start/completion or exception, abort end and final exit. Elapsed values are measured from that phase's dispatch; `abort_elapsed_seconds` measures its existing abort call. These observations use the existing native trace journal and flush points. They add no engine requests, aborts, awaits, periodic writes or timeout changes. Request parameters, recorded tokens, public JSON, rewards and failure classification remain unchanged.

`first_response` is when the client observes a response. With `FINAL_ONLY`, it is not the first decoded token. Cancellation before the final response may have no observed token or engine metrics, even if the engine performed work. Monotonic timestamps are comparable within one process; do not compare their absolute values across hosts.

When an actual `RequestOutput.metrics` object exposes finite numeric fields, `engine_metrics` copies supported fields with vLLM's original names and units. Available queue, scheduling, prefill/decode and model timing fields are retained. Missing values remain absent; the logger does not estimate decode time, convert engine units or subtract engine timestamps from the local clock. Some vLLM versions return no request metrics. A metrics accessor failure is recorded as `engine_metrics_read_error_type` and does not replace the response.

Evaluation manifests/runtime provenance and TRAIN collection closure receipts record the enabled observation configuration. Existing native phase IDs and validation remain the source of truth. The measurements support subsequent DEV/TRAIN diagnosis; they do not supply missing timings for historical runs.
